# How To IRL

## Bare Minimum Requirements

- A Windows computer that can run Docker Desktop and OBS Studio.
- An internet connection and access to your router settings to forward UDP port `5000` for incoming SRTLA streams.

### Recommended

- A system with a video card (GPU) is preferred for running OBS.
- A third-party firewall is highly recommended. My personal recommendation is Malwarebytes Premium.
